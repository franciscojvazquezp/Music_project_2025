# Music_project_2025
This repository includes a file in jupyter notebook where we can find information about the behavior of music plays in several cities of the USA.
# Objective
Taking as reference a dataset that includes information about real data from online music streaming to explore and process information about the listening habits of users in two cities: Springfield and Shelbyville.
# Methodology
**Data cleaning:** <br> 
- The first step was to clean the column names, because they included under scores, spaces and some others characters.  <br>
- Once we got the column names in order, we could see that the dataset included missing values, duplicated explicit values and implicit as well, so it was necesary to clean this kind of issues. <br>
# Exploratory analysis
- The information was clean and ready to start analyzing the column 'city' in order to know the details about two cities where we need to get deeper information. <br>
- Additional to the analysis for each city, we got information for two days in these cities: Monday and Friday. <br>
